# Sound effects

Four tiny placeholder beeps are included. To use your own sounds, replace these files
(keep the same names and .wav / .mp3 format, and update the extension in
`src/services/feedback.ts` if you switch to mp3):

- `correct.wav`  played on Correct
- `skip.wav`     played on Skip
- `tick.wav`     played each second in the last 5 seconds
- `finish.wav`   played when the game ends
